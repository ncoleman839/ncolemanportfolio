# Multi-program Project on E-Commerce Sales Data

For this project, I used two different applications: Excel and Power BI. I wanted to answer one question: How much of the total profit came from American buyers, and what age group brought in the most profit?
First, I downloaded two data files: E-commerce sales data for all customers, and order data which detailed all the orders from that file. Immediately afterwards, I opened the e-commerce sales data file in Excel and used Excel to delete all values that were not from American customers.
Afterwards, I opened both files in Power BI and used the Power Query Editor to ensure that the whole dataset would be visible for both files. I did not want to accidentally omit any important data.
Then, I created a new measure by using the DIVIDE function to divide the e-commerce profit (which only contained US values) by the order data profit (which contained all values worldwide). Then I used a card visual to determine the US profit, finding that it was just under $42 million.
I then immediately used another card visual with the new measure to find that that number represented about 51% of the total profit from the nearly 400,000 entries.
Then, I separated the age groups into young adult (18-39), middle aged (40-59), and older individuals (60+) to find out which group was the most profitable. I found that the young adult buyers generated the most profit.
I thus concluded that young adults contributed the most toward the total American profit, which itself was 51% of the total profit of the entire survey.
